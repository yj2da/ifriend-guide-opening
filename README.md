# I-Friend 27기 오프닝 세레모니 미션 가이드북 웹앱

> 국립부경대학교 I-FRIEND 27기 오프닝 세레모니 아이스브레이킹 빙고 게임 미션 가이드북 (1~16번) 다국어 웹 애플리케이션

## 🌟 주요 기능

1. **4개국어 완벽 지원 (Multilingual)**
   - 한국어(KO), English(EN), 日本語(JP), 中文(CN) 원터치 전환 지원.
   - 모든 1~16번 미션 제목, 상세 조건, 특별 주의사항 및 카테고리 안내 문구 수록.
2. **5초 카운트다운 타이머 (Built-in 5s Timer)**
   - 5.0초 원형 게이지 카운트다운, Web Audio API를 활용한 신호음 효과 및 시간 종료 알림.
   - 각 미션 카드 내에서 '5초 타이머 시작'으로 즉시 연동.
3. **인터랙티브 4×4 빙고판 (Interactive Bingo Board)**
   - 성공한 미션을 터치하여 실시간 체크.
   - 가로 4줄, 세로 4줄, 대각선 2줄 (총 10줄) 빙고 라인 자동 계산.
   - 빙고 달성 시 화려한 폭죽(Confetti) 효과 연출.
   - `#16 럭키 찬스` 기본 프리패스 완료 적용.
4. **번호 퀵 점프 & 실시간 검색**
   - 1~16번 번호 칩 원클릭 시 해당 미션 카드로 부드러운 스크롤 이동.
   - 번호 및 다국어 키워드 실시간 검색 및 카테고리 탭(인상착의, O/X 퀴즈, 액티비티) 필터.
5. **가이드북 QR 코드 팝업**
   - 상단 QR 버튼 클릭 시 팀원들과 공유할 수 있는 가이드북 QR 코드 이미지 표시 및 링크 복사 기능.

## 🚀 실행 및 배포 방법

### 로컬 실행 (Local Dev Server)
```bash
npm install
npm run dev
```
브라우저에서 `http://localhost:5173/`으로 접속합니다.

### 프로덕션 빌드 (Build)
```bash
npm run build
```
`dist/` 폴더에 정적 웹 파일이 번들링됩니다.

### GitHub Pages 배포
```bash
npm install --save-dev gh-pages
npm run deploy
```
